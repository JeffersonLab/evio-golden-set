# evio-golden-set

Reference test material for [JeffersonLab/evio](https://github.com/JeffersonLab/evio):
generators, the canonical digest specification, canon tools, the
cross-library harness, and the golden manifest.

Text and code only. The golden files themselves (~77 MB) are **not**
committed — they are regenerated deterministically by the generators here
and pinned by the digests in the manifest, so a generation on a different
platform is caught either way.
